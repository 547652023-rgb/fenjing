# PDF Chinese font

Noto Sans CJK SC Regular is bundled for vector PDF export. The browser downloads
the font on demand, and exported PDFs embed only the glyphs actually used.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

License: SIL Open Font License 1.1. The license is included alongside this font
and published at `fonts/OFL.txt` in the deployed application.
