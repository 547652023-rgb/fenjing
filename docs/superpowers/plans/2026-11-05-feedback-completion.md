# 图片与编辑反馈补齐

用户已批准按三项建议依次实现，采用现有 React/TypeScript 架构，无新增依赖。

1. 图片：由 ImageCell 报告整批处理生命周期（包括准备、逐张上传、重试），工作台统一计数，避免重复计数。准备时显示状态，完成或失败释放保护。测试：准备未完成、上传失败、连续多图与重试。
2. 撤销：提取可撤销变更筛选，使用与实际应用相同的条件，显示撤销数和因后续修改/删除而跳过的数量。测试：全部撤销、部分修改、全部跳过。
3. PDF：通过 ExportOptions 回调报告图片加载失败，预览保存警告数量，直接导出遇缺图时先展示预览及重试入口；用户可明确下载含缺图标记的 PDF。成功重试清除警告，设置变更不复用旧结果。测试：渲染错误报告、预览警告、重试成功、直接导出避免静默缺图。

每项先运行新增回归测试确认失败，再实现并跑相关测试。最后全套测试、构建、独立审查、合并、推送、等待发布成功。
