# 拍摄日导出包设计（P0）

## 目标

为制片提供可打印、可交接的单个拍摄日交付物：一份 A4 PDF 拍摄通告单和一份可编辑 Excel 镜头执行表。数据以当前拍摄日与镜头排程为唯一来源，避免重复维护。

## 首期范围

- 在拍摄计划中，为已选择的拍摄日提供“导出拍摄包”。
- 生成 `拍摄日通告单 PDF`：标题、日期、地点、集合/收工时间、负责人、备注、按拍摄顺序排列的镜头。
- 生成 `镜头执行表 Excel`：拍摄日信息与镜号、场次、内容、景别、时长、制作状态、运镜、设备、镜头焦段、备注等列。
- 支持浏览器打印 PDF；Excel 导出沿用项目现有文件导出机制。
- 文件名包含项目名、拍摄日标题和日期；无日期时使用“日期待定”。

## 明确不做

- 演员、道具、服化、设备、车辆与餐饮资源库。
- 部门拆分清单、预算、档期/时间冲突提醒。
- 导出历史、版本审批与多人签收。

这些内容保留给后续 P1/P2，避免首期导出功能被生产管理系统化需求拖慢。

## 数据与边界

- 复用 `ShootDay` 的日期、地点、集合/收工、负责人和备注；复用其 `shootOrder` 镜头顺序。
- 仅允许导出已选择的拍摄日；空拍摄日可以导出通告信息，但 Excel 镜头表显示明确空状态。
- 删除拍摄日后不保留其导出入口；镜头仍按既有规则回到待排池。
- 导出读取当前页面已保存的数据；保存中或保存失败时禁用导出并提示先完成保存。

## 界面

在拍摄日摘要旁增加“导出拍摄包”按钮，点击后显示两个明确动作：

1. `打印拍摄通告单（PDF）`：打开适合 A4 纵向打印的通告视图，表头固定，镜头可跨页连续。
2. `导出镜头执行表（Excel）`：下载一张“拍摄日信息”工作表和一张“镜头执行表”工作表。

通告表顶部固定当天关键制作信息；镜头表保留现场手写/追加所需的备注列。导出前显示镜头数量与总时长，方便制片核对。

## 验证

- 单元测试：拍摄日导出数据按 `shootOrder` 排序；空日期、空镜头和缺失字段有稳定占位。
- 组件测试：未选择拍摄日不可导出；保存中不可导出；两种导出动作使用正确的项目与拍摄日数据。
- 文件测试：Excel 包含两张工作表及预期列；打印视图包含通告信息与全部镜头。
- 手工冒烟：创建拍摄日、编入镜头、填写制作资料后分别导出 Excel 与 PDF，核对纸质版分页和文件内容。
