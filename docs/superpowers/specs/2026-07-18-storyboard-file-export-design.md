# 分镜工作台文件导出设计

## 目标

在分镜工作台中提供可直接下载的 Excel 和 PDF 文件。导出由浏览器本地完成，不新增服务器或后台任务配置。

## 用户操作

- 工作台顶部提供“导出 Excel”和“导出 PDF”两个按钮。
- 点击按钮后立即开始生成当前项目文件；生成期间按钮禁用并显示正在导出状态。
- 成功后浏览器自动下载文件，文件名使用“项目名称-分镜表-日期.xlsx”或“项目名称-分镜表-日期.pdf”。
- 失败时在工作台显示中文错误提示，用户可以再次点击导出。

## 导出范围与顺序

- 导出项目中的全部镜头，顺序与工作台当前镜头顺序一致。
- 只导出当前设置为显示的字段。
- 字段顺序严格使用项目字段设置中的显示顺序。
- 文本、数字、日期和选择字段导出当前保存的显示值。
- 没有镜头时仍生成带表头的空文件。

## 图片规则

- 图片字段解析现有远程图片元数据；同一画面单元格最多导出 5 张图片，参考图片字段最多 1 张。
- Excel 中图片放入对应单元格，并按单元格区域拉伸；包含多张图片时在单元格内横向等分排列。
- PDF 中图片按同样规则横向等分并拉伸到对应表格区域。
- 单张图片下载失败不阻止整个文件导出；对应位置显示“图片加载失败”，其余数据继续生成。

## 实现结构

- `src/export/storyboardExport.ts`：把项目转换成稳定的导出模型，负责可见字段排序、镜头值和图片元数据解析、文件名清理。
- `src/export/zip.ts`：使用浏览器原生二进制能力生成 XLSX 所需的 ZIP 容器，不依赖外部软件包。
- `src/export/excelExport.ts`：生成 Office Open XML 工作簿、写入单元格和嵌入图片，然后触发下载。
- `src/export/pdfExport.ts`：用浏览器 Canvas 把分镜表渲染成横向分页图像，再封装为 PDF 并下载；中文由 Canvas 字体渲染。
- `src/export/ExportActions.tsx`：提供两个导出按钮、进行中状态和错误提示。
- `src/workbench/ProjectWorkbench.tsx`：把当前项目交给导出操作组件，不改动项目保存与多人协作流程。

## 错误处理

- 防止用户在同一次导出尚未结束时重复触发。
- 文件生成失败后恢复按钮，并显示“导出失败，请稍后重试”。
- 图片跨域或网络读取失败时使用占位文字，不泄露底层技术错误。
- 导出过程只读取当前项目数据，不修改项目、镜头或图片。
- Excel 和 PDF 生成代码随应用一起发布，不依赖运行时外部 CDN 或第三方软件包站点。

## 测试与验收

- 单元测试覆盖：可见字段及顺序、全部镜头顺序、空项目、图片元数据、多图上限和安全文件名。
- 组件测试覆盖：两个按钮可见、导出函数被正确调用、进行中禁止重复点击、失败提示及重试。
- Excel 测试验证表头、文本值、行顺序和图片嵌入位置。
- PDF 测试验证表头、镜头内容、分页入口和图片失败降级。
- 运行全部现有测试、TypeScript 检查和生产构建，确保多人协作、图片上传和字段设置不受影响。

## 本次不包含

- 不增加筛选、勾选部分镜头或按场景导出。
- 不增加服务器后台导出任务、导出历史或云端文件保存。
- 不改变项目成员的现有编辑权限；能够打开工作台的成员都可以导出当前项目。
