# 参考图片列统一设计

## 目标

让分镜工作台的“参考”列与“画面”列采用相同的图片规则，避免两列出现不同的上传和导出行为。

## 交互与数据

- “参考”列每个镜头最多保存 5 张图片。
- 选择文件和拖拽文件都接受图片；超过上限时保留前 5 张并提示限制。
- 在线项目上传前，图片通过现有的 `prepareStoryboardFrame` 处理为 16:9 居中裁切图。
- 图片在表格中纵向展示，使用已有的固定 16:9 缩略图尺寸与删除操作。
- 本地模式与在线模式保持相同的张数和序列化格式。

## 导出

- 导出模型对“参考”图片与“画面”图片均保留最多 5 张。
- Excel 与 PDF 继续从统一导出模型读取图片，因此无需分别创建图片上限规则。

## 约束

- 不变更其它图片字段的现有单图行为。
- 不触碰用户当前未提交的 `pnpm-lock.yaml`、`src/components/StoryboardTable.test.tsx` 和 `pnpm-workspace.yaml` 改动。

## 验收

1. 参考列文件输入支持多选，表格显示 5 张图片的数量计数。
2. 在线上传参考图调用现有的 16:9 图片预处理逻辑。
3. 本地参考图拖放与文件选择最多保存 5 张。
4. 导出模型为参考列保留最多 5 张图片。
