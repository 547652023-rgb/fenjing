# 16:9 图片上传与裁切设计

## 目标

分镜“画面”列选择或拖拽图片后，在浏览器端居中裁切并压缩为 16:9 JPEG，再上传私有存储；列表预览固定 16:9 并裁切填充。

## 设计

- 新增独立图片预处理模块，输入 `File`，输出命名为 `.jpg` 的 JPEG `File`。
- 预处理以原图居中裁切为 16:9，最长边不超过 1920px，JPEG 质量为 0.88。
- 在线模式和本地模式都使用该模块，选择和拖拽走同一处理路径。
- 上传失败展示网关错误代码；失败文件保留重试入口。
- 画面列的预览卡片固定为 16:9，使用 `object-fit: cover`。

## 边界

- 仅处理画面列图片；参考图片维持现有单图逻辑与展示比例。
- 每个画面最多 5 张图的规则不变。
- 不改变项目、成员或存储访问权限。

## 验收

选择和拖拽图片都能生成 16:9 JPEG，上传成功后显示在列表中；网络或权限失败时显示具体失败原因并允许重试。
